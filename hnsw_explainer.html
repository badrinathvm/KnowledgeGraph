What is Cosine Similarity?

Each text is encoded as a high-dimensional vector. Cosine similarity measures the angle between two vectors — not their length. Score of 1.0 means identical direction (same meaning); 0.0 means perpendicular (unrelated).

Small angle = high similarity · Large angle = low similarity

Total: ~130–150 unique nodes touched out of 9,125. Films like Alien, Speed, or Titanic are never loaded — their plot embeddings point in a completely different direction in the 1536-dim space.

RAM usage: Neo4j keeps the HNSW index structure in memory (a graph of pointers), but NOT all raw vectors. Only the vectors of the ~150 traversed nodes are accessed — the other 8,975 plot embeddings are never read from disk.

5 · The ef Parameter — Accuracy Knob

On Layer 0, HNSW does a beam search. The efQuery (exploration factor) controls how many candidate nodes are kept in the queue. Higher ef = more candidates checked = higher recall, lower speed.

Neo4j exposes this as efQuery in the vector index config. Default is typically 100. If ef < k, HNSW automatically raises it to k.

6 · Why Distant Nodes Are Never Visited

The greedy walk always moves toward the query vector. It can never "accidentally" wander to a far region of the vector space — each hop is strictly closer.
